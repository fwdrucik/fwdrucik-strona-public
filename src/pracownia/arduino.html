ŚwieciPrzerwa

1 s światła i 1 s przerwy. Cały cykl trwa 2 s.

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}

To podgląd diody wbudowanej w Arduino Uno. W kodzie podajemy czas w milisekundach. 1000 ms to 1 s.
